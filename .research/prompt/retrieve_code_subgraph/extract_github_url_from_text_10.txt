# Paper Outline
The methodology involves analyzing the sensitivity of meta-learning algorithms to support data, query data, and tasks. Based on these findings, four distinct data augmentation modes are defined: Support augmentation (applied to inner-loop fine-tuning data), Query augmentation (applied to outer-loop evaluation data), Task augmentation (increasing the number of possible tasks by augmenting whole classes), and Shot augmentation (artificially amplifying the shot at test time or during training). Various augmentation techniques (e.g., CutMix, MixUp, Self-Mix, Rotation, Horizontal Flip, Random Erase) are explored within these modes. The core methodological contribution is Meta-MaxUp, which extends the MaxUp strategy to meta-learning by selecting augmentations from a pool that maximize loss during training, formulated as a minimax optimization problem. The study primarily focuses on metric learning approaches and differentiable solvers for meta-learning.
