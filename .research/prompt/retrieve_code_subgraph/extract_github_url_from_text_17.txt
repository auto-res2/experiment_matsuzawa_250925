# Paper Outline
GraphSAINT's core methodology involves constructing minibatches by directly sampling subgraphs from the training graph, rather than sampling nodes or edges across GCN layers. This resolves neighbor explosion because a full GCN is then built on the small, complete subgraph. To address bias introduced by non-identical node/edge sampling probabilities, it proposes aggregator normalization (αu,v = pu,v / pv) for feature propagation and loss normalization (λv = |V| * pv) for minibatch loss. These probabilities are estimated via pre-processing by repeatedly running the sampler. For variance reduction, optimal edge probabilities (pe ∝ |∑ℓ b(ℓ)e|) are derived, simplifying to pe ∝ 1/deg(u) + 1/deg(v) based on graph topology. The paper details several light-weight samplers: Random Node Sampler (P(u) ∝ ||˜A:,u||^2), Random Edge Sampler (P((u,v)) ∝ 1/deg(u) + 1/deg(v)), and Random Walk-based Samplers (regular Random Walk and Multi-dimensional Random Walk), all returning node-induced subgraphs. The method decouples sampling from forward/backward propagation, allowing seamless integration with architectures like JK-net and GAT.
