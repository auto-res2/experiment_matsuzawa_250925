# Paper Outline
The core methodology involves formulating the sampling variance optimization as an adversary bandit problem. Instead of directly computing intractable optimal sampling distributions, the approach maintains nonparametric estimates of the sampler. These estimates are iteratively updated towards optimal variance as partial knowledge about sampled neighbors is acquired. The reward for each action (choosing a set of neighbors) is defined as the negative derivative of the sampling variance. Two bandit algorithms are proposed: (1) GNN-BS, based on the adversary Multi-Armed Bandit (MAB) setting, where a single neighbor is chosen k times and the sampler is updated by EXP3. (2) GNN-BS.M, based on MAB with multiple plays, which uses an efficient k-combination sampler (DepRound) to select a k-element subset of neighbors once, and updates the sampler using EXP3.M. For attentive GNNs, adjusted feedback attention values are used to approximate true attention values given only sampled neighborhoods.
