# Paper Outline
The core methodology involves adapting standard image augmentation techniques to operate on frozen features extracted from pretrained vision transformers. First, the two-dimensional feature representations (f ∈ RN×C) are reshaped into a three-dimensional format (f∗ ∈ R√N×√N×C). Then, a deterministic feature-to-image mapping (tf→x) scales feature values from their native range (R) to a standard image range (e.g., [0,1] or [0,255]) using min-max normalization. An image augmentation (ax) is applied to these scaled features, and an inverse mapping (tf←x) transforms them back to the original feature value range. The study investigates eighteen reformulated augmentations, including geometric, crop & drop, stylistic, and other types. Three FroFA variations are explored: Default FroFA (single random value across the entire feature), Channel FroFA (cFroFA, independent random values per channel, global min/max scaling), and Channel2 FroFA (c2FroFA, independent random values per channel, per-channel min/max scaling). A lightweight Multi-Head Attention Pooling (MAP) head is trained on these augmented frozen features.
