# Paper Outline
The core methodology involves formulating the optimization of sampling variance as an adversary bandit problem. Instead of computing an intractable optimal sampling distribution at each iteration, the approach maintains nonparametric estimates of the sampler and updates it iteratively based on partial knowledge from sampled neighbors. The reward for choosing a set of neighbors is defined as the negative derivative of the sampling variance. Two bandit algorithms are proposed: (1) GNN-BS, based on a multi-armed bandit (MAB) setting, where a single neighbor is sampled and repeated 'k' times, with updates done using EXP3. (2) GNN-BS.M, based on MAB with multiple plays, which uses an efficient k-combination sampler (DepRound) to select a combinatorial set of 'k' neighbors at once, with updates done using EXP3.M. For attentive GNNs, the algorithms are extended by defining adjusted feedback attention values to approximate true attention values, as unnormalized attentions are the only observable values during sampling. The effective variance for GNN-BS is derived directly, while for GNN-BS.M, an approximated effective variance is used based on Jensen's inequality.
