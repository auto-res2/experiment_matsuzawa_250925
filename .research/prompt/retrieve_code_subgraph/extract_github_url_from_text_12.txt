# Paper Outline
TWA reframes weight averaging as a subspace training task. Given a set of candidate weights, it constructs a low-dimensional subspace where the averaged solution is optimized. Instead of directly using highly correlated weights as bases, TWA employs simple decentralization and normalization to create basis vectors for each layer. The optimization of weighting coefficients (β) occurs within this subspace, using gradient projection to ensure updates stay within the defined space. TWA initializes with the SWA solution. An efficient distributed training scheme is developed to handle large-scale problems by partitioning the projection matrix across multiple GPUs and using all-reduce operations for parallel gradient computation. Further memory reduction is achieved through low-bit (e.g., 4-bit) uniform min-max quantization of the projection matrix. TWA offers two variants: TWA-t, which optimizes coefficients using training data, and TWA-v, which uses a small held-out validation set for more efficient and effective averaging.
