# Paper Outline
The core methodology involves adapting 'model soups' for GNNs. It starts by creating multiple instances (K) of the same GNN architecture, referred to as 'soup ingredients,' sharing a common random initialization. These ingredients are trained independently and in parallel on different GPUs, with slight variations in hyperparameters (learning rate, weight decay, seed values, etc.). After independent training, the 'soup' is prepared using a greedy interpolation procedure (Algorithm 1). This procedure sequentially adds each model as a potential ingredient, keeping it only if it improves validation performance through an optimal linear interpolation ratio (alpha). For large graphs where the entire graph data cannot fit in memory, the method employs data-centric model soups by leveraging state-of-the-art graph sampling (node-wise, edge-wise, layer-wise) and graph partitioning (e.g., ClusterGCN with METIS) mechanisms for mini-batch training of the candidate ingredients (Algorithms 2 and 3). Notably, there is no intermediate communication of model weights during the training of individual ingredients; merging only occurs post-training.
