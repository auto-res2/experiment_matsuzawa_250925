# Experimental Design
- Strategy: Experiment 1: Cross-domain Few-shot Benchmark (Domain-conditioned Spectral Basis)
Goal: Show that AdaSProNet’s hyper-network H_ϕ can bend the spectral sub-space to each domain, outperforming single-basis methods when source and target differ strongly.
Setup
• Datasets: mini-ImageNet → test on natural images (Meta-Dataset/Imagenet), AND train on mini-ImageNet but test on dermatology PAD-UFES-20 (medical) and Birds (fine-grained). 500 episodes each.
• 5-way 1-shot & 5-shot.
• Models: AdaSProNet (full), Spectral-ProtoNet (global basis), ProtoNet, FLUTE.
• Hardware: single A100 (batching 16 episodes). Runs <48 h.
Metrics
• Mean episode accuracy; paired t-test at 95 % CI.
• Expected Calibration Error (ECE).
• Active rank R_t distribution per domain.
• Inference latency per query.
Expected Result
• AdaSProNet wins +2 – 3 % acc. on natural, +4 – 6 % on medical; ECE halves vs. Spectral-ProtoNet.
• Active rank adapts: avg 7 for natural, 3 for medical, 10 for fine-grained; latency scales accordingly (<1.3× ProtoNet).
Demonstrates
Adaptive, domain-conditioned basis yields higher accuracy and better calibration without global overhead.

Experiment 2: Rank-Sparsity & Capacity Efficiency Stress-Test
Goal: Quantify how Gumbel-gated rank selection lets the network match task intrinsic complexity, avoiding over-/under-fitting and saving FLOPs.
Setup
• Synthetic controllable dataset: Omniglot characters (low intrinsic dimension), CUB-200 fine-grained birds (high).
• Generate “mixed” meta-episodes where intrinsic rank is controlled by adding Gaussian directions to embeddings before support/query split.
• Compare: (a) AdaSProNet, (b) AdaSProNet w/ rank fixed to median 8, (c) Spectral-ProtoNet (global rank 10), (d) ProtoNet.
• Measure: accuracy vs. injected intrinsic rank (1…15), average active rank, GFLOPs/query.
Expected Result
• Accuracy of AdaSProNet tracks oracle upper bound within <1 %; fixed-rank degrades outside sweet spot (±4 %).
• FLOPs scale linearly with active rank; up to 40 % saving on low-rank tasks.
• Gumbel gates select correct rank ±1 in 85 % episodes.
Demonstrates
Automatic rank-sparsity matches capacity to task difficulty, maintaining performance while reducing computation.

Experiment 3: Continual Few-shot Stream with Safety Monitoring
Goal: Validate continual sub-space update and uncertainty-aware rejection in a deployment-like stream.
Setup
• 20 sequential domains from Meta-Dataset (ordered: Aircraft→Flowers→Signs→Dermatology, etc.). 5-way 5-shot per domain, 1,000 episodes/domain in arrival order. FIFO buffer size 1 k.
• Models: AdaSProNet (with/without online update), CWR-ProtoNet, FLUTE.
• After each new domain, replay 200 held-out episodes from all previous domains to measure forgetting and calibration drift.
Metrics
• Accuracy current domain; forgetting Δacc previous domains.
• ECE drift over time.
• Coverage vs. risk when rejecting predictions with confidence <τ (τ∈{0.1…0.5}).
• GPU memory & update time.
Expected Result
• AdaSProNet w/ updates retains ≥97 % of original accuracy on earlier domains (forgetting ≤1 %); no-update variant drops 6 %. Baselines ≥7 %.
• ECE remains ≤5 % for updated AdaSProNet, drifts to 12 % without updates.
• At τ=0.3, critical false positives drop 2× with only 8 % coverage loss.
• Update step <0.5 s on A100, <500 MB RAM.
Demonstrates
Lightweight continual adaptation preserves knowledge, sustains calibration, and provides actionable uncertainty estimates suitable for safety-critical continual few-shot deployment.

Experiment 1  Cross-domain Few-shot Benchmark
────────────────────────────────────────────────────────
1. Goal
   Quantitatively verify that the hyper-network H_φ lets AdaSProNet bend its spectral basis to different domains, outperforming single-basis alternatives while remaining well-calibrated and computationally frugal.

2. Datasets & Episode Construction
   • mini-ImageNet (Train/Val)  : 64 × 84×84 classes
   • Meta-Dataset-ImageNet (Test natural)  :   1 000 held-out episodes
   • PAD-UFES-20 dermoscopy (Test medical)  :     500 episodes (filtered to ≥20 images/class)
   • Meta-Dataset-Birds (CUB-200) (Test fine-grained)  : 500 episodes
   All episodes are 5-way {1,5}-shot, 15 queries / class.

3. Pre-processing
   • Resize shorter side → 92, centre-crop 84 (for Conv-4 & ResNet-12)
   • Per-image mean / std normalisation using ImageNet statistics
   • Data-augmentation (support only): random horizontal flip, colour jitter (±0.1) – identical for all methods
   • Medical images: Dermoscopy hair artefacts removed with DullRazor v3 (footnote¹).

4. Models
   AdaSProNet-Conv4-32d,  AdaSProNet-ResNet12-640d  (ours)
   Baselines: Spectral-ProtoNet (global V); ProtoNet; FLUTE; (*optionally*) ProtoDiff†
   †ProtoDiff is excluded from dermoscopy due to unavailable public weights – a re-implementation is provided.

5. Hyper-parameters & Search (performed on validation split of mini-ImageNet only)
   • Backbone lr ∈ {1e-3, 5e-4}; Hyper-network lr ∈ {5e-4, 1e-4}; cosine decay
   • Gumbel τ ∈ {0.3, 0.5, 0.7}; λ_rank ∈ {0.05, 0.1, 0.2}
   • β for topological regulariser ∈ {0.3, 1.0}
   • ν initialised to 5, learned with lr 1e-4
   Grid size 2×3×3×2×1 = 36;  handled with Ray-Tune on 4 GPUs (≈7 h)

6. Train/Val/Test Protocol
   • Meta-train on mini-ImageNet, 1 000 episodes/epoch × 120 epochs
   • 5 random seeds {11,19,23,29,31}.  Observe mean ± std over seeds.
   • Selection: best val accuracy (early stopping patience = 20 episodes).
   • Final metrics reported as average over all seeds; paired t-test computed episode-wise.

7. Evaluation Metrics
   Primary: Mean episode accuracy
   Secondary: Expected Calibration Error (15 bins), Negative Log-Likelihood (NLL), Active rank 𝔼[R_t], latency (ms / query) on single A100.

8. Robustness Checks
   • Additive Gaussian pixel noise σ∈{0.04,0.08}; accuracy-drop measured.
   • 50 % query images JPEG-compressed Q=30 (distribution shift).
   • FGSM ε=2/255 adversarial queries – using backbone gradients.

9. Resource Logging
   • FLOPs: measured with ptflops per query averaged over 200 episodes
   • Memory: peak GPU util from nvidia-smi logging
   • Wall-clock: training + inference time (reported as median over seeds)

Experiment 3  Continual Few-shot Stream with Safety Monitoring
────────────────────────────────────────────────────────
1. Goal
   Assess continual basis updates (novelty D) and uncertainty-aware rejection (novelty C) in a realistic domain stream.

2. Dataset Stream & Splits
   Sequential domains drawn from Meta-Dataset (Aircraft → QuickDraw → Fungi → … → Dermoscopy) – total 20.
   Per domain: 5-way 5-shot support, 15 queries/class, 1 000 episodes.
   Held-out Replay Buffer: randomly reserve 200 episodes/domain (never used for update – only forgetting evaluation).

3. Models & Variants
   • AdaSProNet + online update (ours)
   • AdaSProNet – frozen (no update)
   • CWR-ProtoNet (continual baseline)
   • FLUTE (continual transformer-based)

4. Continual Update Implementation
   • FIFO buffer max 1 000 support embeddings
   • Every 250 incoming episodes do: Incremental PCA (rank≤16) → 1 SGD step on H_φ (lr 2e-4, 20 iters)
   • No backbone gradients (frozen) → memory ≤500 MB, time <0.5 s on A100

5. Metrics
   • Acc_current, Acc_prev (average over all previous domains) → Forget = Acc_prev_before – Acc_prev_after
   • ECE drift (15 bins) per domain
   • Coverage-Risk curve: vary τ∈{0.1…0.5}; report AUROC_reject = ∫(1-coverage)×TPR dτ
   • Runtime: update_time, additional GPU memory

6. Hyper-parameters Fixed (validated in Exp-1)
   lr_hyper = 2e-4; τ = 0.5; ν initial = 5; buffer=1 k.

7. Robustness – Abrupt Domain Shift
   After 10 domains, inject adversarial domain “Textures” with high-frequency patterns; measure detection by confidence <0.3.

8. Example Pseudocode
   ```python
   for domain in domains:
       for episode in stream(domain):
           acc = model.forward_episode(episode)
           if episode.is_support:
               buffer.push(episode.support_emb)
       if step % 250 == 0:
           model.incremental_update(buffer)
       evaluate_forgetting(model, replay_loader)
   ```

9. Reporting
   Plot forgetting vs. time, ECE drift, and coverage-risk; tabulate update overhead.
